# Project Rules for AI Assistants

Unpacked MV3 Chrome extension, no build step. See `CLAUDE.md` for the full
project guide.

## Hard rules
- **Never move the merge logic into the popup.** The popup dies with its window,
  and that window is often one of the ones being emptied. All window and tab work
  belongs in `background.js`.
- **Always re-pin a pinned tab after moving it.** Chrome clears the `pinned` flag
  on a cross-window move. Dropping the `chrome.tabs.update(id, {pinned: true})`
  call silently unpins the user's pinned tabs.
- **Always move tab groups with `chrome.tabGroups.move()`.** Never let a grouped
  tab into the `chrome.tabs.move()` batch — it leaves the group without a word.
- **Don't add permissions.** `tabGroups` + `system.display` is the whole set.
  Adding `tabs` would grant URL and title access the extension has no use for.
- **Don't add dependencies or a build step.** This is plain files Chrome loads
  directly; keeping it that way is the point.
- **Don't assume a window is mergeable.** Filter to `type === "normal"` and
  `!incognito` every time — both move APIs reject the rest.

## Install convention
Loaded unpacked from the clone, per Chrome profile. It cannot be automated:
Chrome ignores `--load-extension` as of Chrome 137, and non-Web-Store `.crx`
sideloading has been blocked since Chrome 33 without an admin policy. Don't add
tooling that pretends to install it.

## Diagnostics
Service-worker console via `chrome://extensions` → **service worker**. A failed
merge sets a red `!` badge on the toolbar button, cleared next time the popup
opens. The extension card's **Errors** button should be empty after a run.
